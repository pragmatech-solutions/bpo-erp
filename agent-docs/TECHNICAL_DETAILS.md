This project is developed in next.js and with a mongodb database.
Yarn is used as the package manager, only use yarn for package management
Frontend design library is shadcn. And no other library for ui is to be added.
Husky is set up for git hooks
Auto formatting of code is done to remove the headache of formatting from AI, plus keeps the code clean and no whitespace incompatability.
Testing part is done by the developer. So just do the coding. Make sure the build happens, and respond back. Developer would do the work of checking whether things work or not.
